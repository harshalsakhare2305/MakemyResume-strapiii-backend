# 📄 MakeMyResume — Strapi Backend

> **Headless CMS backend for the MakeMyResume application, powered by Strapi v4.**

This repository contains the **backend API** for the MakeMyResume app — a resume builder platform. It is built with **Strapi v4**, an open-source headless CMS that provides a fully customizable REST & GraphQL API, a powerful admin panel, and flexible content type management.

The Strapi project lives inside the `makemyresume/` folder and serves as the data layer for the frontend resume builder app.

---

## 🏗️ Architecture Overview

```
MakeMyResume (Full Stack)
├── 🖥️  Frontend         →  React / Next.js (separate repo)
└── ⚙️  Backend (this)   →  Strapi v4 Headless CMS
        └── makemyresume/
                ├── REST API  (auto-generated by Strapi)
                ├── Admin Panel  (/admin)
                ├── Content Types (Resume, Template, User, etc.)
                └── SQLite / PostgreSQL database
```

---

## ✨ Features

- 🔧 **Strapi v4 Headless CMS** — Auto-generated REST & GraphQL APIs from content types
- 🗂️ **Content Type Builder** — Define resume sections (Personal Info, Education, Experience, Skills, Projects, etc.) via the Strapi admin UI
- 🔐 **Built-in Authentication** — JWT-based user auth with role-based access control (RBAC)
- 👤 **User & Role Management** — Manage user permissions via the Strapi admin panel
- 📁 **Media Upload** — Upload profile pictures and assets via Strapi's media library
- 🌐 **REST API** — Auto-generated RESTful endpoints for all content types
- ⚡ **GraphQL Support** — Optional GraphQL plugin for flexible queries
- 🗄️ **Database Agnostic** — Works with SQLite (dev), PostgreSQL, MySQL (prod)
- 🛡️ **CORS & Security** — Configurable CORS policies for frontend integration

## 🚀 Getting Started

### Prerequisites

- Node.js **v18.x** or **v20.x** (Strapi v4 requirement)
- npm or yarn
- SQLite (default, no setup needed) or PostgreSQL for production

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/harshalsakhare2305/MakemyResume-strapiii-backend.git
   cd MakemyResume-strapiii-backend/makemyresume
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables — create a `.env` file in the `makemyresume/` folder:
   ```env
   HOST=0.0.0.0
   PORT=1337
   APP_KEYS=your_app_key_1,your_app_key_2
   API_TOKEN_SALT=your_api_token_salt
   ADMIN_JWT_SECRET=your_admin_jwt_secret
   TRANSFER_TOKEN_SALT=your_transfer_token_salt
   JWT_SECRET=your_jwt_secret

   # Database (SQLite default — no changes needed for dev)
   DATABASE_CLIENT=sqlite
   DATABASE_FILENAME=.tmp/data.db

   # For PostgreSQL (production)
   # DATABASE_CLIENT=postgres
   # DATABASE_HOST=localhost
   # DATABASE_PORT=5432
   # DATABASE_NAME=makemyresume
   # DATABASE_USERNAME=your_db_user
   # DATABASE_PASSWORD=your_db_password
   ```

4. Start the development server:
   ```bash
   npm run develop
   ```

5. Open the Strapi Admin Panel at [http://localhost:1337/admin](http://localhost:1337/admin) and create your first admin account.

## 🌐 API Endpoints

Once running, the API is available at `http://localhost:1337/api/`. All content types defined in Strapi auto-generate REST endpoints. Example:

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/resumes` | Get all resumes |
| `GET` | `/api/resumes/:id` | Get a single resume |
| `POST` | `/api/resumes` | Create a new resume |
| `PUT` | `/api/resumes/:id` | Update a resume |
| `DELETE` | `/api/resumes/:id` | Delete a resume |
| `POST` | `/api/auth/local/register` | Register a new user |
| `POST` | `/api/auth/local` | Login and receive JWT |

> 💡 Use the **Strapi Admin Panel** → `Settings → API Tokens` to generate tokens for authenticated requests.
